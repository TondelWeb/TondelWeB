What to do next

  1. Open proposals.csv. In the approve column, write yes or no for each fix. Leave it blank if you're not sure yet.
  2. Send the file back. You'll receive an import file containing only the fixes you approved.
  3. Before importing, back up your products (Shopify admin → Products → Export).
  4. Import in Shopify (Products → Import) and tick “Overwrite products with matching handles”.
  5. Flags below need a human decision. Nothing flagged is ever changed by us.

How this check works

  • Each store SKU is matched to the supplier file. Every mapped spec is compared, along with barcodes, duplicate SKUs and barcodes, units, titles and variant options.
  • A fix is proposed only when an exact supplier cell supports it. That cell is shown with its file, row and column.
  • Unclear supplier values (ranges, “approx.”, “equivalent”, wrong units) are flagged, never copied.
  • Changes you reject are remembered and not proposed again.

What we never do

  • Invent specs, certifications, voltage, compatibility, prices or inventory.
  • Log into or write to your store. You approve every change and import it yourself.
  • Edit titles, variant options, prices or stock.
  • Promise more traffic, ad performance or sales.
